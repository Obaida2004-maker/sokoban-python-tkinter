# Sokoban Python Tkinter

This project is a Sokoban puzzle game developed in Python using Tkinter.

Sokoban is a grid-based puzzle game where the player must push boxes onto target positions while avoiding walls and obstacles. The project includes multiple levels, graphical sprites, movement logic, and score tracking.

## Features

- Graphical user interface using Tkinter
- Grid-based Sokoban gameplay
- Player movement in four directions
- Box pushing mechanics
- Wall, box, player, and goal detection
- Multiple levels loaded from external files
- Image-based sprites for the game elements
- Score tracking using a JSON file
- Simple and interactive game logic

## Technologies Used

- Python
- Tkinter
- JSON
- Jupyter Notebook
